# User Reference

This section contains reference documentation for DocSentinel's configurable
features. Each page covers a specific subsystem, its configuration keys, valid
ranges, defaults, and concrete examples.

## Pages

| Page | Purpose |
|------|---------|
| [Rules](rules.md) | The single table of every check (DS101–DS301): profile, severity, activation, title, what it reports, fault class and config keys. Drift-tested against the rule registry and `docsentinel rules`. |
| [Statistical Checks](statistical-checks.md) | DS201 text complexity, DS202 duplicate text, and DS203 low-information content: all six configurable keys, valid ranges, defaults, finding formats, and worked examples. |
| [Configuration Reference](configuration.md) | All Milestone 0005 fast-profile policy options for DS104–DS118: anchor, heading, section, reference, fence, table, navigation, asset, path-boundary, document-identity, deprecated-reference, and naming policy options. |
